# SDK LexxCE для ESP32

Базовый режим CE — кооперативный цикл с короткими обработчиками. Поддержка задач FreeRTOS поставляется отдельным
компонентом. [Выбор режима и состав SDK](execution.md).

Для сборки из checkout доступен `find_package(LexxCE)`.
[Подключение через CMake](../docs/cmake-packages.md#lexxce).

Для сборки прошивки ESP32 используйте каталог `lib/` и `include/` из одного SDK. В `lib/` находятся ядро, порт ESP-IDF и
два компонента исполнения. Автономный пример подключает выбранный
компонент. [Пример blink для ESP-WROOM-32](examples/blink/README.md) содержит описание платы, параметры прошивки и точку
входа приложения.

[Цифровой вход](digital-input.md) поддерживает события уровня, серии кликов и удержание кнопки.

[Цифровой выход](digital-output.md) управляет уровнем GPIO и используется в примере blink.

[Драйверы GPIO в описании платы](board-gpio.md) — назначение входов и выходов, получение объектов по имени и совместный
опрос входов.

[Кнопка и LED](examples/button_led/README.md) — самостоятельный пример обработки кликов на ESP-WROOM-32.

[Шина I²C и BME280](examples/i2c_sensor/README.md) — описание именованной шины, сканирование и чтение регистра. Для
переноса старого проекта на новый SDK добавьте компонент ESP-IDF `esp_driver_i2c` в зависимости адаптера `lexxos_ce`,
как в примере. Используйте библиотеку и заголовки из одного комплекта.

[SPI](spi.md) — общая шина, отдельные CS, режимы и частоты. [Пример двух устройств](examples/spi_devices/README.md)
содержит локальную конфигурацию платы. Для нового SDK адаптер ESP-IDF также подключает `esp_driver_spi`.

[Аналоговый вход и PWM](analog-pwm.md) — именованные каналы и
автономный [пример потенциометра и LED](examples/analog_pwm/README.md). Адаптер приложения подключает `esp_adc` и
`esp_driver_ledc`.

[Аналоговый выход](analog-output.md) — ЦАП с начальным кодом и контролем
диапазона. [Автономный пример](examples/analog_output/README.md) меняет уровень раз в секунду. Адаптер SDK также
подключает `esp_driver_dac`.

[Проект API периферии и параметров](../docs/ce-peripherals-storage.md) описывает реализованные интерфейсы и проект
хранения параметров.

## Сборка самого SDK

Из корня LexxOS с установленным окружением ESP-IDF для ESP32 выполните:

```sh
cmake --preset ce-sdk-esp32
cmake --build --preset ce-sdk-esp32
```

Готовая поставка находится в `build/ce-sdk-esp32/sdk/esp32/`. Каталог `lib/` содержит статические библиотеки
компонентов, а
`include/` — её публичный интерфейс и заголовок проверки совместимости. В `manifest.json` записаны версии
инструментария, параметры сборки и контрольные суммы архивов. Поставку сопровождают `LICENSE` и `NOTICE`.

Один SDK подходит для нескольких устройств на классическом ESP32 с совместимым окружением ESP-IDF. Параметры сборки
библиотеки заданы в `ports/espidf/sdkconfig.ce.defaults`. При смене целевого чипа, версии ESP-IDF или несовместимых
настроек ESP-IDF/FreeRTOS потребуется соответствующая сборка библиотеки.

## Архив для распространения

Из корня репозитория выполните `python3 tools/release.py --ce-only`. Команда собирает
SDK заново и создаёт `dist/LexxOS-<версия>/LexxCE-<версия>-sdk-esp32.zip`.
Тот же комплект входит в полную сборку выпуска. Для разработки доступен
`--allow-dirty`, который добавляет к имени версии метку снимка исходников.

Распакуйте ZIP, откройте его каталог в терминале ESP-IDF и соберите пример:

```sh
idf.py -C examples/blink -DLEXXOS_CE_SDK="$PWD" build
```
