# Цифровой выход CE

`DigitalOutput` управляет уровнем одного GPIO. Приложение передаёт GPIO-службы и при инициализации задаёт вывод и
начальный уровень. По умолчанию выход стартует с низкого уровня.

| Метод                   | Результат                                                                                                                            |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| `state()`               | Последний уровень, подтверждённый драйвером: `DigitalOutputState::Low` или `High`. До настройки и после ошибки возвращает `Unknown`. |
| `toggle()`              | Меняет известный уровень на противоположный.                                                                                         |
| `setHigh()`, `setLow()` | Устанавливают высокий и низкий уровень соответственно.                                                                               |
| `write(high)`           | Устанавливает уровень, переданный как `bool`.                                                                                        |

Инициализация и операции записи возвращают `true` при успехе. После ошибки записи можно восстановить известное состояние
явным вызовом `setLow()` или `setHigh()`. Пока состояние неизвестно, `toggle()` возвращает `false`. После ошибки
конфигурации требуется успешный `initialize()`.

```cpp
#include <lexxos/devices/output/digital_output.h>

bool testOutput(lexxos::platform::PlatformServices const& platform) {
    lexxos::devices::DigitalOutput led(platform.gpio);
    if (!led.initialize({2})) {
        return false;
    }
    return led.setHigh() && led.toggle() &&
           led.state() == lexxos::devices::DigitalOutputState::Low;
}
```

Для GPIO2 с активным высоким уровнем `setHigh()` включает светодиод. При активном низком уровне он включается через
`setLow()`. Полярность нагрузки задаёт приложение. За подтверждение напряжения на нагрузке отвечает отдельный вход
обратной связи.

Управляйте выводом через один экземпляр из одной задачи или сериализуйте вызовы на уровне приложения. Таблица GPIO-служб
должна жить дольше экземпляра. Работающий пример с переключением раз в секунду находится в каталоге `blink` поставки.
