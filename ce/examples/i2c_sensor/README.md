# Проверка шины I²C на ESP-WROOM-32

При загрузке пример выводит в UART0 (115200) выбранные GPIO и сканирует 7-битные адреса от `0x08` до `0x77`. Для каждого ответа появляется строка `ACK`. На адресах `0x76` и `0x77` пример дополнительно читает регистр `0xD0` через repeated START. Значение `0x60` соответствует BME280. Для остальных ответивших адресов отображается только адрес. После сканирования приложение завершает работу. [Описание регистров BME280, Bosch](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf).

Шина `sensors` описана в `main/board.cpp`. Настройки по умолчанию — SDA на GPIO21, SCL на GPIO22, частота 100 кГц. Проверьте разводку своей платы и общий GND. У линий SDA/SCL должны быть подтяжки к 3,3 В, они могут уже стоять на модулях. У BME280 для I²C вывод CSB подключается к VDDIO, а уровень SDO выбирает адрес.

Скопируйте каталог примера и в окружении ESP-IDF 6.0.2 выполните:

```sh
idf.py -DLEXXOS_CE_SDK=/path/to/sdk menuconfig
idf.py build
idf.py -p PORT flash monitor
```

Выводы задаются в меню **I2C sensors**. Для сборки с выбранными по умолчанию выводами достаточно `idf.py -DLEXXOS_CE_SDK=/path/to/sdk build`. Можно также указать два пути через `LEXXOS_CE_LIBRARY` и `LEXXOS_CE_INCLUDE_DIR`.

В приложении `system.devices().i2cBus("sensors")` возвращает объект шины. Метод `writeRead(address, tx, txSize, rx, rxSize)` выполняет запись номера регистра и чтение одним обменом с общим STOP в конце. Обе длины должны быть больше нуля. Для отдельных операций есть методы `probe`, `write` и `read`.

Адаптер подключает ядро, порт ESP-IDF и выбранный компонент исполнения. По умолчанию используется `cooperative`, выбор задаётся через `-DLEXXOS_CE_EXECUTION=freertos`. Все архивы компонентов должны находиться рядом в каталоге `lib/`.
