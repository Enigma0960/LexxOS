# Кнопка и светодиод на ESP-WROOM-32

Подключите нормально разомкнутую кнопку между **GPIO27 и GND**. Вход использует внутреннюю подтяжку вверх. Светодиод на **GPIO2** загорается при высоком уровне. Выводы задаются в локальном меню **Button / LED**. Начальное состояние светодиода — выключен.

Скопируйте папку примера и в терминале ESP-IDF 6.0.2 выполните из неё:

```sh
idf.py -DLEXXOS_CE_SDK=/path/to/sdk build
idf.py -p PORT flash monitor
```

| Действие | Что проверить |
| --- | --- |
| Один клик | После окна 300 мс светодиод переключается. |
| Два быстрых клика | После паузы светодиод включается. |
| Три быстрых клика | На третьем отпускании светодиод выключается. |
| Удержание | Метки `hold` и `long hold` появляются на 1,5 и 10 с. |
| Перезагрузка с зажатой кнопкой | LED стартует выключенным. Первое отпускание даёт только `released`. |

UART0 (115200) выводит время от загрузки, подтверждённые переходы входа, распознанный жест и состояние выхода. Дребезг подавляется за 25 мс, входы опрашиваются одной задачей каждые 5 мс. Описание платы находится в `main/board.cpp`, соответствие жестов действиям — в `main/app_main.cpp`.

Адаптер подключает ядро, порт ESP-IDF и выбранный компонент исполнения. По умолчанию используется `cooperative`, выбор задаётся через `-DLEXXOS_CE_EXECUTION=freertos`. Все архивы компонентов должны находиться рядом в каталоге `lib/`.
