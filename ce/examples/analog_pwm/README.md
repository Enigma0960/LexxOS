# Потенциометр и яркость LED на ESP-WROOM-32

Автономный пример загружает CE, получает `AnalogInput("knob")` и `PwmOutput("led")` из описания платы и связывает их в
коротком обработчике кооперативного цикла. Опрос — каждые 20 мс, вывод сырого кода АЦП и заданного заполнения — раз в
секунду через UART0, 115200 бод. Терминал и shell не используются.

## Подключение

| Сигнал                       | По умолчанию                    |
|------------------------------|---------------------------------|
| Крайние выводы потенциометра | 3V3 и GND                       |
| Средний вывод потенциометра  | GPIO34, ADC1                    |
| Светодиод                    | GPIO2, активный высокий уровень |
| UART0 TX / RX                | GPIO1 / GPIO3                   |

Подойдёт потенциометр около 10 кОм. Внешнему светодиоду нужен последовательный ограничительный резистор; встроенный LED
платы может уже иметь его. Все устройства имеют общую землю. На аналоговый вход нельзя подавать 5 В. У верхнего края
поворота потенциометра АЦП может насыщаться раньше 3,3 В: пример масштабирует сырой код, а не предполагает линейный
диапазон 0–3,3 В. GPIO34 не имеет внутренней подтяжки.

## Сборка

Скопируйте папку примера. В окружении ESP-IDF 6.0.2 укажите только каталог готового SDK:

```sh
idf.py -DLEXXOS_CE_SDK=/path/to/sdk build
```

Из корня распакованного дистрибутива:

```sh
idf.py -C examples/analog_pwm -DLEXXOS_CE_SDK="$PWD" build
```

Можно указать `LEXXOS_CE_LIBRARY=/path/to/lib/liblexxos_ce.a` и `LEXXOS_CE_INCLUDE_DIR=/path/to/include` вместо каталога
SDK. Библиотека порта и выбранный компонент исполнения должны лежать рядом с ядром. Исходники LexxOS для сборки не
нужны. По умолчанию подключается `cooperative`; приложение не создаёт задачи CE. В ESP32 системный FreeRTOS остаётся
частью ESP-IDF.

Через `idf.py menuconfig` → **LexxCE: Analog input and PWM** меняются выводы и полярность LED. Имена, частота PWM 1
кГц, разрешение 10 бит, канал и таймер заданы в `main/board.cpp`. Там же находятся разрядность АЦП и ослабление. GPIO2
не следует одновременно объявлять как `statusLed` или цифровой `userGpio`.

После загрузки консоль сообщает состояние ядра, наличие калибровки АЦП и частоту таймера. Яркость изменяется
пропорционально сырому коду. При ошибке чтения или записи обработчик пытается выключить PWM и останавливается; неудача
выключения сообщается отдельно.

Этот этап проверен сборкой и линковкой. Проверка на подключённой плате выполняется отдельно.
