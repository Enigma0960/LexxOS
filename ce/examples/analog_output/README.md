# Аналоговый выход ESP-WROOM-32

Пример загружает CE и получает `AnalogOutput` с именем `reference`. На GPIO25
по очереди задаются коды **0 → 64 → 128 → 191 → 255 → 0** с интервалом около
секунды. UART0 на 115200 бод сообщает состояние загрузки и заданный код.
Работа выполняется коротким обработчиком кооперативного цикла, без shell.

## Подключение

Измеряйте напряжение между GPIO25 и GND высокоомным вольтметром или осциллографом.
Это сигнальный выход ЦАП, не источник питания нагрузки. Внешнее напряжение
на выход не подаётся. Код в консоли не является измерением напряжения.

В меню **LexxCE: Analog output** можно выбрать GPIO26 вместо GPIO25.
Имя канала, разрядность и начальный код находятся в `main/board.cpp`.
Выбранный GPIO не должен одновременно использоваться другим устройством.

## Автономная сборка

Скопируйте папку примера. В окружении ESP-IDF 6.0.2 задайте каталог готового SDK:

```sh
idf.py -DLEXXOS_CE_SDK=/path/to/sdk build
```

Из корня распакованного дистрибутива:

```sh
idf.py -C examples/analog_output -DLEXXOS_CE_SDK="$PWD" build
```

Вместо каталога можно указать `LEXXOS_CE_LIBRARY=/path/to/lib/liblexxos_ce.a` и
`LEXXOS_CE_INCLUDE_DIR=/path/to/include`. Библиотека порта и компонент исполнения
должны находиться рядом с ядром. Все `.a` и заголовки берутся из одного SDK.
Исходники LexxOS не нужны; плата, разметка flash и параметры приложения локальны.

По умолчанию подключается компонент `cooperative`. Приложение не создаёт задач CE;
системный FreeRTOS на ESP32 остаётся частью ESP-IDF. Для выбора другого GPIO
запустите `idf.py menuconfig` после задания пути к SDK.

При ошибке записи обработчик пытается установить нулевой код и останавливается.
После остановки ядро и объект остаются живы. При освобождении драйвера канал
отключается; это не гарантирует удержание нулевого напряжения.

Пример предназначен для проверки уровней. Интервалы кооперативного цикла не
обеспечивают точную частоту генератора сигналов. Проверка на плате выполняется
отдельно от сборки и линковки.
