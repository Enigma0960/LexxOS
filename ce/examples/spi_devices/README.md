# Два SPI-устройства на ESP-WROOM-32

Пример запускает CE, создаёт два объекта SPI и выводит их параметры в UART0 на 115200 бод. Сообщение `driver ready` подтверждает инициализацию драйвера. Наличие внешнего устройства подтверждается чтением его регистра или другой операцией его протокола.

Описание платы и устройств находится в `main/board.cpp`. Общие линии по умолчанию — SCK GPIO18, MOSI GPIO23 и MISO GPIO19. Устройство `first` использует CS GPIO25, Mode0 и 1 МГц. Устройство `second` использует CS GPIO26, Mode3 и 2 МГц. Оба CS активны низким уровнем. Это пример конфигурации, распиновку конкретного стенда следует сверить перед подключением.

Скопируйте папку и соберите её с библиотекой и заголовками одного SDK в окружении ESP-IDF 6.0.2.

```sh
idf.py -DLEXXOS_CE_SDK=/path/to/sdk menuconfig
idf.py build
```

В меню **SPI devices** задаются выводы. Значение `-1` отключает MOSI или MISO, хотя бы одна линия данных обязательна. Частоты, режимы и имена находятся в описании платы.

В программе используйте `system.devices().spiBus("first")` и `system.devices().spiBus("second")`. Для передачи команды можно вызвать `queuedSpiTransfer` из `lexxos/devices/bus/spi_transfer.h`. Он захватывает очередь контроллера, применяет режим и частоту, опускает CS, выполняет обмен и поднимает CS. Байты команды определяет протокол подключённой микросхемы.

Адаптер подключает ядро, порт ESP-IDF и выбранный компонент исполнения. По умолчанию используется `cooperative`, выбор задаётся через `-DLEXXOS_CE_EXECUTION=freertos`. Все архивы компонентов должны находиться рядом в каталоге `lib/`.
