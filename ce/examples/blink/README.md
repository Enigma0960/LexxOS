# Blink для ESP-WROOM-32

Скопируйте папку `blink` в удобное место. Для сборки понадобятся окружение ESP-IDF для ESP32, архивы ядра, порта ESP-IDF
и компонента исполнения
из `lib/`, а также каталог публичных заголовков из той же поставки SDK. Пример рассчитан на ESP-WROOM-32 с flash 4 МБ и
светодиодом на GPIO2, который загорается при высоком уровне.

Плата объявляет выход `led` в таблице `userGpio`. При загрузке ядро задаёт уровень выключенного светодиода, а приложение
получает готовый драйвер через `system.devices().digitalOutput("led")`.

## Сборка

Откройте терминал ESP-IDF и перейдите в скопированную папку. Для этой сборки SDK использованы ESP-IDF 6.0.2 и Xtensa GCC
15.2.0. Если архив лежит в `lib/`, а заголовки в `include/`, укажите их общий каталог:

```sh
idf.py -DLEXXOS_CE_SDK=/path/to/esp32 build
```

Каталоги библиотек и заголовков можно хранить отдельно. Все архивы компонентов должны находиться рядом с
`liblexxos_ce.a`. В этом случае укажите оба пути:

```sh
idf.py -DLEXXOS_CE_LIBRARY=/path/to/liblexxos_ce.a \
       -DLEXXOS_CE_INCLUDE_DIR=/path/to/include build
```

Каталог `include/` должен содержать экспортированное дерево заголовков, включая `lexxos/ce/build_config.h`. При сборке
этот заголовок проверяет совместимость чипа, версий ESP-IDF и GCC, настроек FreeRTOS и C++. Пути к SDK сохраняются в
каталоге сборки.

## Настройки платы

| Файл примера                 | Что менять                                                                            |
|------------------------------|---------------------------------------------------------------------------------------|
| `main/board.cpp`             | Описание платы, доступные выводы и отладочный UART, которые приложение передаёт ядру. |
| `main/Kconfig.projbuild`     | Параметры светодиода в меню **Blink / ESP-WROOM-32**.                                 |
| `sdkconfig.defaults`         | Начальные значения GPIO и полярности, размер flash, UART и имя таблицы разделов.      |
| `partitions.csv`             | Размещение разделов во flash.                                                         |
| `main/blink_application.cpp` | Инициализация и интервал переключения светодиода.                                     |

Чтобы изменить готовую конфигурацию, запустите `idf.py menuconfig`, выберите вывод и полярность в **Blink /
ESP-WROOM-32**, затем выполните `idf.py build`. Чтобы задать значения для новых копий проекта, измените
`CONFIG_BLINK_LED_GPIO` и `CONFIG_BLINK_LED_ACTIVE_LOW` в `sdkconfig.defaults`. Эти значения применяются при создании
каталога сборки. В обоих случаях используется тот же архив ядра.

## Прошивка и проверка

Из папки примера подставьте порт платы:

```sh
idf.py -p /dev/ttyUSB0 flash monitor
```

ESP-IDF записывает загрузчик, таблицу разделов и приложение `build/LexxCEBlink.bin`. В macOS порт обычно имеет вид
`/dev/cu.usbserial-…`, в Windows — `COM3`. Для выхода из монитора нажмите `Ctrl+]`.

UART0 (GPIO1 TX, GPIO3 RX, 115200, 8N1) служит для вывода сообщений. После загрузки ядра светодиод выключен.
Кооперативный обработчик
меняет его состояние каждые 1000 мс и сообщает об успешной записи GPIO. Полный цикл занимает около двух секунд.
Ожидаемый вывод после сообщений ROM и ESP-IDF:

```text
LexxCE: kernel loading
[core] The platform, scheduler, device registry, and EventBus are ready.
[core] initialization complete; LED interval: 1000ms
[LED] GPIO2: OFF (level=0)
[core] cooperative LED loop started.
[LED] GPIO2: ON (level=1)
[LED] GPIO2: OFF (level=0)
```

По умолчанию используется кооперативный цикл. Для отдельной задачи выберите `-DLEXXOS_CE_EXECUTION=freertos`. Оба режима
используют один комплект SDK.
