# LexxCP

LexxCP — файловый менеджер на Python/PySide для передачи файлов между
компьютером и LexxOS через консоль UART/USB-serial. Он использует команды:

- `yrx [path]` — принять файл на LexxOS с компьютера;
- `ysend <path> [name]` — отправить файл VFS LexxOS на компьютер.

YMODEM/CRC реализован на Python; внешние утилиты `sb`/`rb` не требуются.

## Требования

Рекомендуется Python 3.10 или новее. Из каталога `tools/lexxcp`:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

В Windows активируйте окружение так:

```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

Из каталога `tools/lexxcp`:

```bash
python -m lexxcp
```

Либо из корня репозитория:

```bash
python tools/lexxcp/main.py
```

## Порядок работы

1. Соберите и прошейте LexxOS с командами `yrx` и `ysend`.
2. Запустите LexxOS и дождитесь приглашения shell.
3. Откройте LexxCP на компьютере.
4. Выберите последовательный порт и скорость.
5. Нажмите **Connect** (подключиться).
6. Левая панель показывает файловую систему компьютера, правая — VFS LexxOS.
7. **Upload →** передаёт локальный файл на LexxOS.
8. **← Download** сохраняет файл LexxOS на компьютере.

## Ограничения

Передаётся один файл за раз. Синхронизация каталогов, пакетная передача
и продолжение прерванной загрузки могут быть добавлены поверх этого транспорта.

Shell работает с текстом, а YMODEM — с двоичными пакетами в том же UART.
Поэтому LexxCP строго соблюдает последовательность: отправка команды,
ожидание байта согласования отправителя/получателя, передача YMODEM,
ожидание нового приглашения LexxOS.
