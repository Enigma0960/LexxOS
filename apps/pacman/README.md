# Lexx Pac-Man (первый игровой патч)

Небольшая автономная игра для виртуальной машины RV32I LexxOS. Использует псевдографику ANSI,
события клавиатуры и новый SDK-интерфейс звука `lexx::play_tone()`.

## Сборка

```sh
cmake --preset apps
cmake --build --preset apps --target app-pacman
# или make -C apps/pacman
```

Результат: `build/apps/pacman.lexx`. Скопируйте файл на смонтированную SD-карту и запустите:

```text
/mnt/sd/pacman.lexx
```

**Важно:** новая прошивка LexxOS должна содержать `syscall_milliseconds=19` и
`syscall_play_tone=20`. Без обновления хоста запуск прежних `.lexx` не меняется,
но данная версия игры получит `unsupported-syscall`. Обновление SDK без обновления
прошивки недостаточно.

## Управление

- Стрелки / `WASD` — движение, начинают игру после стартового экрана;
- `Enter` — начать или продолжить после потери жизни;
- `P` / пробел — пауза;
- `M` — включить/выключить звук (только ручное отключение);
- `T` — воспроизвести проверочный тон 880 Гц / 300 мс / громкость 200 независимо от mute;
- `R` — начать заново;
- `Q` — выход (аппаратная клавиша `Esc` также завершает игру).

Собирайте все точки (`.`), получая по 10 очков. Большие точки (`o`) дают 50 очков
и примерно шесть секунд позволяют поедать призраков (`M`) за 200 очков.
У игрока три жизни. Когда все точки собраны, уровень завершён победой.

Игра продолжает работать без аудиоустройства: ошибка звука не приводит к отключению
всех последующих эффектов. Обычные игровые звуки теперь громче и длиннее.

Строка `SFX` показывает включено ли воспроизведение (`ON/OFF`), результат
последнего звукового системного вызова (`DEVICE: UNTESTED/OK/ERROR`),
счётчики попыток (`TX`) и неуспешных запросов (`ERR`).
`DEVICE: OK` означает **только** то, что LexxOS приняла тон: реальное воспроизведение
зависит от настроек Audio в GUI эмулятора. Для проверки нажмите `T` на стартовом
экране; успешный тон должен быть слышен ещё до начала движения.
Если `DEVICE: ERROR`, проверьте, что .lexx собран заново с `audio` capability,
в SD-папку скопирована новая версия и выполнена `sync`.
Если `DEVICE: OK`, но звука нет, проверьте `Host output` в настройках GUI и
сравните с командой `beep`.

Для интерфейса достаточно терминала шириной 40 символов и высотой 22 строки;
на меньшем экране может понадобиться уменьшение масштаба шрифта.

## Архитектура

- `game.h/.cpp` — игровая логика, не связанная с SDK; её можно тестировать обычным C++20-компилятором;
- `pacman.cpp` — ввод, цветной ANSI-рендеринг, обновление по таймеру и простые звуковые эффекты;
- `runtime.cpp` — freestanding RV32I helpers; пока дублирует набор `fileman`, в дальнейшем стоит
  вынести их в общую библиотеку SDK.

Ограничения первой версии: один фиксированный лабиринт, два упрощённых призрака
без поиска пути, без сохранения рекордов и без фоновой музыки.
