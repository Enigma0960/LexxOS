# Lexx Snake

Классическая «Змейка» для внешней RV32I VM LexxOS. Не зависит от аппаратной платформы:
только текстовая консоль (ANSI), клавиатура, системные часы и опциональный `lexx::play_tone()`.

## Сборка и запуск

Из корня LexxOS:

```sh
cmake --preset apps
cmake --build --preset apps --target app-snake
```

Готовая программа: `build/apps/snake.lexx`. Перенесите её на SD-карту эмулятора, выполните
`sync`, если играете через `--sd-dir`, и запустите:

```text
/mnt/sd/snake.lexx
```

Игра использует системные вызовы `milliseconds=19` и `play_tone=20`, доступные в
LexxOS `Release/0.1.0`. В манифесте приложения включено разрешение `audio`.
Для игрового экрана достаточно терминала приблизительно **40×20** символов.

## Управление

- Стрелки / `WASD` — направление, начинает игру на стартовом экране;
- `Enter` — начать движение;
- `P` / пробел — пауза / продолжить;
- `R` — начать заново;
- `M` — включить / выключить эффекты;
- `T` — проверочный сигнал 880 Гц, 300 мс, даже если звук выключен;
- `Q` / аппаратная клавиша `Esc` — выйти в консоль LexxOS.

Собирайте красные звёздочки (`*`), избегайте стен и столкновения с собственным телом.
Голова — `@`, тело — `o`. За каждую еду — 10 очков и один сегмент роста. Каждые
четыре съеденные звёздочки игра ускоряется; минимальный интервал 86 мс.
Когда всё поле заполнено змейкой, засчитывается победа. Лучший результат
запоминается **только до завершения процесса** (запись на SD не требуется).

Если звук не слышен, проверьте `DEVICE:OK/ERROR`, счётчики `TX/ERR` и клавишу `T`.
Ошибка звукового вызова не выключает последующие эффекты, как и в Pac-Man.

## Исходники

- `game.h` / `game.cpp` — автономная логика: движение, коллизии, еда, ускорение;
- `snake.cpp` — интерфейс LexxOS, ввод, ANSI-графика и эффекты;
- `runtime.cpp` — freestanding RV32I helpers (набор, совместимый с `fileman` и `pacman`);
- `../../tests/test_snake.cpp` — нативные тесты без эмулятора и SDK.

Нативная проверка игровой логики без RISC-V toolchain:

```sh
c++ -std=c++20 -Wall -Wextra -Werror apps/snake/game.cpp tests/test_snake.cpp -o /tmp/lexx-snake-test
/tmp/lexx-snake-test
```

Пока один режим: стены смертельны, без телепортации через край и сохранения рекордов.
