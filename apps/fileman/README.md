# Lexx Commander — файловый менеджер `.lexx`

Двухпанельный файловый браузер LexxOS, выполняемый гостевой RV32I VM. Использует capabilities
`storage-read` и `storage-write`: поддерживает просмотр, копирование, перемещение, переименование и удаление файлов и каталогов.

## Сборка

Из корня проекта:

```sh
cmake --preset apps
cmake --build --preset apps
```

Создаётся `build/apps/fileman.lexx`. Понадобится RISC-V GCC или Clang/LLD/llvm-objcopy. Для работы нового
просмотрщика **требуется обновление LexxOS**, содержащее `syscall_seek = 12`; иначе старая прошивка завершит просмотр с
ошибкой `unsupported-syscall`.

Общие требования и выбор компилятора описаны в [сборке приложений](../README.md).

## Запуск

```text
/mnt/sd/fileman.lexx
/mnt/sd/fileman.lexx /mnt/sd /tmp
```

Первый необязательный аргумент — начальный каталог левой панели, второй — правой. При недоступности используется `/`.

## Управление

| Клавиша           | Действие                             |
|-------------------|--------------------------------------|
| `↑/↓` (`k/j`)     | Выбор элемента                       |
| `Tab` или `←/→`   | Переключить панель                   |
| `Enter`           | Войти в каталог или просмотреть файл |
| `Backspace`       | Родительский каталог                 |
| `F3` (`v`)        | Просмотр файла                       |
| `F5` (`c`)        | Копировать в каталог другой панели  |
| `F6` (`m`)        | Переместить в каталог другой панели |
| `n`               | Переименовать выбранный элемент     |
| `F8`, `Delete`    | Удалить с подтверждением            |
| `F9` (`o`)        | Настройки                            |
| `r`               | Обновить активный каталог            |
| `q`, `Esc`, `F10` | Выход из файлового менеджера         |

Копирование и перемещение используют каталог противоположной панели. Существующий объект назначения
не перезаписывается. Удаление каталога рекурсивное: `Y` подтверждает, любая другая клавиша отменяет.
При переименовании `Enter` принимает новое имя, `Esc` отменяет ввод.

### Настройки (F9 или o)

- `↑/↓` — выбор параметра;
- `←/→` — изменение ширины или высоты интерфейса на два символа/строки;
- `Enter`, `←/→` — переключение отображения скрытых файлов;
- `Esc`, `q`, `F9` — закрыть настройки.

Настраивается **размер текстового интерфейса**, не физический размер окна Qt. Диапазон: 40–100 столбцов, 14–40 строк; по
умолчанию 50×22. Терминал должен иметь не меньше выбранного размера: автоматического определения его геометрии в
гостевом SDK пока нет. Смена размеров очищает экран и перерисовывает обе панели.

Скрытые записи с именами, начинающимися на `.`, по умолчанию отображаются (как в предыдущей версии). Исключения `.` и
`..` не выводятся ни в одном режиме. При смене настройки панели обновляются, по возможности сохраняя выделение.

**Настройки действуют только до выхода из приложения.** Постоянное сохранение настроек пока не реализовано.

### Режим просмотра (Enter / F3)

| Клавиша                         | Действие            |
|---------------------------------|---------------------|
| `PageDown`, `↓`, `→` (`j`, `d`) | Следующая страница  |
| `PageUp`, `↑`, `←` (`k`, `u`)   | Предыдущая страница |
| `Esc`, `q`, `F3`, `Backspace`   | Вернуться к панелям |

Просмотрщик открывает файл только на чтение, позиционируется через `lexx::seek(fd, offsetLow, offsetHigh)` и читает
порциями по 128 байт **только текущую страницу**. Число байт страницы определяется количеством видимых строк: перенос
строк и ширина окна учитываются при вычислении смещения следующей страницы. Поддерживается текст ASCII: байты вне
печатного ASCII заменяются на `.`, символ `Tab` расширяется пробелами; кодировка UTF-8 пока не декодируется.

Для возврата назад хранится ограниченная история 128 смещений (не данные страниц). После прокрутки дальше 128 страниц
самые старые смещения забываются; это ограничение навигации назад, а не размера файла. Размер файла и позиционирование
представлены двумя 32-битными словами, что позволяет работать и с большими 32-битными смещениями, если это поддерживает
файловая система.

## Реализация

- `apps/fileman/fileman.cpp` — панели, настройки и viewer;
- `apps/fileman/input_reader.{h,cpp}` — преобразование UART/ANSI в команды;
- `apps/fileman/file_operations.{h,cpp}` — операции с файлами и каталогами;
- `apps/fileman/runtime.cpp` — freestanding функции для RV32I без расширения M;
- `sdk/lexx/lexx.h` — `syscall_seek = 12`;
- `src/lexxos/external_program/external_program_runner.cpp` — read-only `seek` для гостевого fd;
- `emulator/lexxos_emu/terminal_widget.py` — передача F9 через `CSI 20 ~`.

Directory ABI: syscall 10 (`list_directory`, 8 записей), 11 (`stat`). Reader ABI: 8 (`open_read`), 3 (`read`), 12
(`seek`), 9 (`close`). В текущем приложении максимум 96 видимых записей на панель, каталог просматривается до 4096
физических записей.

## Ограничения

- Нет постоянного сохранения настроек.
- При изменении каталога во время получения нескольких страниц списка результаты могут быть несогласованы; `r` обновляет
  каталог.
- Цвета оформлены через ANSI SGR, на устройствах без поддержки ANSI-цветов они могут отображаться монохромно.
- Управление ожидает UART/ANSI терминал и совместимые escape-последовательности.
