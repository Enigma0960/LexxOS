# Lexx Tetris

Тетрис для внешней RV32I VM LexxOS, без зависимости от конкретной платы. Использует
ANSI-терминал, `lexx::poll_key`, `lexx::milliseconds` и опциональный `lexx::play_tone`.

## Сборка и запуск

Из корня LexxOS:

```sh
cmake --preset apps
cmake --build --preset apps --target app-tetris
```

Скопируйте `build/apps/tetris.lexx` в папку SD эмулятора, выполните `sync` для
двустороннего обмена с виртуальной FAT32, затем запустите в LexxOS:

```text
/mnt/sd/tetris.lexx
```

Рекомендуемый размер терминала — **не меньше 40×27** символов: поле занимает
20 строк, а ещё несколько строк используются для счёта и управления. При необходимости
уменьшите шрифт в GUI. Используются те же системные вызовы и audio capability, что
и в работающих `pacman.lexx` и `snake.lexx`.

## Правила

- Поле **10×20**; все **7 тетромино** выбираются с помощью перемешиваемого набора (7-bag).
- Справа показывается **следующая фигура**; прозрачный силуэт обозначает место падения.
- Заполненные горизонтальные ряды удаляются; за 1/2/3/4 ряда сразу — **100/300/500/800 × уровень** очков.
- Мягкое падение: **1 очко** за клетку; жёсткое: **2 очка** за клетку.
- Уровень растёт каждые 10 линий. Скорость от 700 мс до 100 мс за шаг.
- Повороты используют небольшие смещения у стен и пола, **не полный стандарт SRS**.
- При невозможности создать следующую фигуру — конец игры.
- Лучший результат хранится в памяти приложения, до завершения процесса.

## Управление

| Клавиша               | Действие                                            |
|-----------------------|-----------------------------------------------------|
| Стрелка влево / A     | Сдвинуть фигуру влево                               |
| Стрелка вправо / D    | Сдвинуть фигуру вправо                              |
| Стрелка вверх / W / X | Повернуть по часовой стрелке                        |
| Z                     | Повернуть против часовой стрелки                    |
| Стрелка вниз / S      | Мягкое падение                                      |
| Пробел                | Жёсткое падение (сразу поставить фигуру)            |
| Enter                 | Начать игру                                         |
| P                     | Пауза / продолжить                                  |
| R                     | Новая игра                                          |
| M                     | Включить/выключить эффекты                          |
| T                     | Тестовый тон 880 Гц, 300 мс, работает даже при MUTE |
| Q / аппаратная Esc    | Выйти в консоль                                     |

На экране есть `SFX:ON/OFF`, `DEVICE:UNTESTED/OK/ERROR`, `TX` и `ERR`, чтобы
отличить ошибку аудиовызова от отсутствия host-воспроизведения. Ошибки звука **не отключают** игру и следующие эффекты.

## Код и тесты

- `game.h/.cpp`: самостоятельная логика фигур, поворотов, линий и подсчёта очков.
- `tetris.cpp`: интерфейс SDK, рендеринг, ввод, время и звук.
- `runtime.cpp`: обязательные арифметические и memory helpers для freestanding RV32I.
- `../../tests/test_tetris.cpp`: тесты на обычном C++20 без эмулятора.

Нативный запуск:

```sh
c++ -std=c++20 -Wall -Wextra -Werror apps/tetris/game.cpp tests/test_tetris.cpp -o /tmp/lexx-tetris-test
/tmp/lexx-tetris-test
```
