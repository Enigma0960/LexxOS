# Диагностика SDK LexxOS (`sdk-demo.lexx`)

Переносимая гостевая программа RV32I. Служебный API самой ОС напрямую не вызывается.

## Сборка

Соберите цель `apps` существующей конфигурации компьютера или прошивки, например:

```sh
cmake --build build/host-full --target apps -j 12
# Результат: build/apps/sdk-demo.lexx
```

Скопируйте файл в доступный VFS-каталог и запустите:

```text
lexx:/> lexx-run /mnt/sd/sdk-demo.lexx --once /tmp
lexx:/> lexx-run /mnt/sd/sdk-demo.lexx /tmp
lexx:/> lexx-run /mnt/sd/sdk-demo.lexx --once /mnt/sd
```

Последний пример проверяет корректность VFS на доступной для записи SD.
Скорость носителя измеряют штатные `sd-bench`, `sd-hw-bench` и диагностика
платы. Выполнение большого `.lexx` с той же карты не даёт чистого замера SD.

Интерактивные клавиши:

- `B` — повторить измерения VM/ECALL;
- `G` — повторить быстрый тест прямоугольников RGB565;
- `S` — повторить десятисекундную анимацию логотипа;
- `P` — сравнить 48 полных кадров с 48 кадрами отдельных спрайтов и HUD;
- `A` — запустить пятисекундную анимацию атласа alpha8;
- `Q` — выход.

`P` и `A` не входят в `--once`; `P` вызывает `wait_idle()` после обоих
вариантов. Заставка один раз запускается при старте. Ввод подчиняется
маршрутизации активной программы и обработке Ctrl+C.

Ресурсы `:/img/lexxos.lxim` и `:/img/banner.lxim` встроены в `.lexx`,
однократно загружаются, проверяются по CRC и кешируются в памяти ОС.
Анимация стирает только прежний прямоугольник логотипа с учётом его
масштаба и рисует изображение на новом месте. Каждую секунду заставка
выбирает другой масштаб из ×1/×2/×4/×8/×16, ограниченный размерами
дисплея; масштабирование выполняет ОС. HUD показывает среднюю частоту
отправки кадров, прошедшее время и текущий масштаб. `orb.lxim` —
прозрачный четырёхкадровый атлас RGB565/alpha8;
исходный прямоугольник выбирает гостевой `graphics::SpriteAnimation`.
Гостевой кадровый буфер и вычисления с плавающей точкой не требуются.
Ресурсы не перечитываются с SD для каждого кадра. Ограничение 25 отправленных
кадров/с (период 40 мс) не является измерением обновления LCD. При завершении
право управления экраном возвращается консоли.

Ожидаемые результаты:

- `memory` — выделенная гостевая память и объявленный стек, не свободная куча ОС;
- `rtc` — секунды UTC при настроенных и действительных часах, иначе недоступно;
- `vfs` — небольшая проверка записи, чтения, сравнения и удаления без замера скорости;
- `vm` — время ALU/памяти и ECALL; относительные результаты без вывода о частоте CPU;
- `graphics` — доступно при RGB565 `DisplayDevice`, фокусе и разрешении Graphics;
- `audio`, `devices` — доступны при реальной реализации сервиса платформой.

Манифест объявляет возможности и память. `lexx_pack.py` отклоняет
несоответствия `--cap`, `--memory`, `--stack`; права при исполнении задаёт
заголовок `.lexx`. Старые манифесты продолжают работать. Сохраняется предел
гостевой памяти 64 КиБ; расширение квот и профилей памяти относится к
[плану SDK и графики](../../docs/lexxos-sdk-graphics-roadmap-v2.md).
