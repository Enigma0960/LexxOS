# LexxOS 0.1.0

Первая публичная версия LexxOS: FreeRTOS, shell, VFS/FatFs, драйверы устройств
и запуск внешних RV32I-программ. Версии ОС и Python-эмулятора — `0.1.0`.
На 2026-10-24 выпуск подготовлен к финальной сборке, но ещё не опубликован:
релизный commit и тег пока не зафиксированы.

## Состав выпуска

Для каждой платы поставляются отдельные minimal и full — всего 12 firmware ZIP:

| Плата | Публичный board id | Особенности |
| --- | --- | --- |
| Cardputer ADV | `m5stack_cardputer_adv` | Не предназначен для обычного Cardputer |
| PicoCalc + Pico | `picocalc_pico` | RP2040, без Wi-Fi |
| PicoCalc + Pico W | `picocalc_pico_w` | RP2040, CYW43 Wi-Fi |
| PicoCalc + Pico 2 | `picocalc_pico2` | RP2350, без Wi-Fi |
| PicoCalc + Pico 2 W | `picocalc_pico2w` | RP2350, CYW43 Wi-Fi |
| JC-ESP32P4-M3-DEV | `jc_esp32p4_m3_dev` | ESP32-P4, Ethernet, Hosted Wi-Fi через C6 |

Тринадцатый ZIP содержит только приложения из `apps/`: `fileman`, `pacman`,
`snake`, `tetris`. Примеры из `examples/` в выпуск не входят. Эмулятор и остальные
профили доступны в исходниках; отдельных бинарных архивов для них в этом наборе нет.

Minimal сохраняет базовое оборудование, shell, файловую систему и запуск `.lexx`.
Full добавляет диагностику и поддерживаемые дополнительные/экспериментальные
системы; их включение не означает аппаратную проверку. В обоих RP2040 PicoCalc
профилях Game Boy, MIDI и GPIO analyzer ограничены по SRAM. Подробности —
[матрица команд](command-matrix.md) и [профили плат](boards.md).

## Установка

1. Выберите ZIP для точной модели платы и нужного flavor; проверьте его SHA-256
   по общему `SHA256SUMS`. Распакуйте архив.
2. Следуйте `INSTALL.txt` внутри firmware ZIP. PicoCalc прошивается через BOOTSEL
   файлом `firmware.uf2`; модуль Pico/Pico W/Pico 2/Pico 2 W должен совпадать.
   Публичные PicoCalc-сборки рассчитаны на **JCS southbridge firmware**:
   [инструкция PicoCalc](boards/picocalc_pico_w.md), [JCS](picocalc-jcs-keyboard-firmware.md).
3. Для ESP32 используйте приведённую в архиве команду esptool 5.x с фактическими
   offsets и своим последовательным портом. JC-архив не обновляет сопроцессор C6;
   его совместимая Hosted firmware устанавливается отдельно по
   [инструкции платы](boards/jc_esp32p4_m3_dev.md).
4. Из apps ZIP скопируйте папку `lexx/` в корень SD. В ОС программы доступны как
   `/mnt/sd/lexx/fileman.lexx` и аналогичные пути. См. [руководство apps](../apps/README.md).
5. После загрузки проверьте `version`, `board`, `help`, `storage` и `ls /mnt/sd`.

Перед обновлением сохраните данные SD и конфигурацию. При смене разметки flash
сохраните также нужные данные flash. Приложения используйте из того же выпуска;
совместимость произвольных старых `.lexx` не заявляется.

## Сборка из исходников

Требования к SDK и toolchain — в [инструкции сборки](build.md).

```sh
git submodule update --init --recursive third_party/FreeRTOS
cmake --preset minimal-picocalc_pico
cmake --build --preset minimal-picocalc_pico
```

Замените preset на `minimal-<board id>` или `full-<board id>` из таблицы.
Для полного набора архивов из чистого commit:

```sh
cmake --preset release
cmake --build --preset release
```

Результат — `dist/LexxOS-0.1.0/`: 13 ZIP, `SHA256SUMS`, `release.json`.
Каждый ZIP включает инструкции, manifest и лицензии. Режим `--allow-dirty`
создаёт отдельный набор с меткой `dev`; такой набор не является чистым релизом.
Подробности — [упаковка релиза](release-packaging.md).

## Проверенность и известные ограничения

Все 12 профилей прошли сборку и упаковку development-снимка 2026-10-24.
CRC и контрольные суммы 13 архивов проверены. Это не аппаратный прогон этих образов.
[Итоговый отчёт](tests/release-0.1.0-validation.md) фиксирует исходные версии и границы проверок.

- JC: ранее прошли короткие проверки full/minimal, shell, SD/VFS, reboot и загрузки
  `.lexx`. Ethernet link up подтверждён; обычный ping при двух активных интерфейсах
  не доказывает выбор Ethernet. Потери ping в сети автора приняты как особенность
  сети: явной сетевой проблемы на стороне платы не обнаружено.
- Один незапрошенный `SW_CPU_RESET` после чтения заголовков `.lexx` не воспроизвёлся
  в коротком повторе. Первопричина и дефект ОС не установлены; наблюдение принято
  как неблокирующее, требуется статистика эксплуатации.
- После выхода из игр наблюдался остаточный UART-ввод. Источник не локализован;
  перед следующей командой убедитесь, что строка shell очищена. Скорость и игровой
  процесс не являются проверенными характеристиками этого выпуска.
- Экран, звук и внешняя клавиатура минимально проверены автором отдельно.
  Внешние устройства не требуются для базового регресса. Game Boy, MIDI,
  GPIO analyzer и прочие экспериментальные системы в текущую приёмку не входят.
- Для Cardputer ADV и всех четырёх PicoCalc текущий набор подтверждён сборкой;
  аппаратный прогон финального кандидата не выполнен. Исторические проверки W
  не распространяются автоматически на новые non-W профили.
- Длительные проверки отложены для [ручного запуска](tests/release-0.1.0-jc-manual-duration.md).
  Многочасовая стабильность не заявляется. PicoCalc power/southbridge зависит от
  версии JCS; RP2040 имеет ограниченный запас памяти. Simulator не моделирует
  точные временные характеристики MCU.

## Финальные действия перед публикацией

Состав и инструкции определены. Остались операции над окончательным кандидатом:

- [ ] Согласовать индекс и рабочие изменения, зафиксировать release commit.
- [ ] Повторить локальные проверки кандидата по [инструкции](development-checks.md)
  и собрать чистый набор архивов; сверить manifest, лицензии, SHA256 и INSTALL.
- [ ] Записать фактически выполненные аппаратные проверки; для остальных оставить
  отметку «на устройстве не проверено». Отложенные ручные сценарии не отмечать PASS.
- [ ] Создать тег `v0.1.0` на проверенном commit, указать дату и опубликовать
  13 ZIP, `SHA256SUMS`, `release.json` в GitHub Release.
