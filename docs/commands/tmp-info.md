# `tmp-info`

show /tmp diagnostic information.

## Справка shell

```text
tmp-info - show /tmp diagnostic information

Shows RAM-backed /tmp usage and currently allocated files.

Usage:
  tmp-info
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
