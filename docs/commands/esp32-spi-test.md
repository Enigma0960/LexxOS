# `esp32-spi-test`

Инициализирует SPI-шину платы для LCD/TF и отправляет такты при неактивном chip select. Требует подходящей шины; сейчас
не зависит от TEST_COMMANDS.

## Использование

```text
esp32-spi-test
```

## Наличие в сборке

Условие регистрации: ESP-IDF. Наличие команды не подтверждает подключение устройства
или поддержку всех операций конкретной конфигурацией. Подробности группировки:
[матрица команд](../command-matrix.md).

[Descriptor и реализация](../../src/lexxos/apps/core/esp32_spi_test_program.cpp) — источник параметров;
`help esp32-spi-test` показывает справку текущей сборки.
