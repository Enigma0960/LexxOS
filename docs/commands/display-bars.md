# `display-bars`

draw display color bars.

## Справка shell

```text
display-bars - draw display color bars

Draws a simple RGB565 color bar pattern for display diagnostics.

Usage:
  display-bars [name]

Arguments:
  name - device name
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
