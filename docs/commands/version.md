# `version`

show LexxOS build and feature milestone.

## Справка shell

```text
version - show LexxOS build and feature milestone

Shows LexxOS version, build date, platform, board and the current filesystem feature milestone.

Usage:
  version
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
