# `ln`

Создаёт переносимый ярлык LexxOS с расширением `.lnk` для встроенной команды или внешней программы `.lexx`.

## Синтаксис

```text
ln [--bg|--fg] [--delay-ms N] [--force] <program> <file.lnk> [-- args...]
```

- `--fg` — запуск на переднем плане (по умолчанию).
- `--bg` — запуск фоном, если целевая программа поддерживает фоновые процессы.
- `--delay-ms N` — дополнительная задержка при запуске через `/sys/autostart`, от 0 до 600000 мс.
- `--force` — разрешить перезапись существующего файла ярлыка.
- Всё после `--` записывается в ярлык как отдельные аргументы. Для аргумента с пробелами используйте кавычки.

## Примеры

```text
ln board /mnt/sd/board.lnk
ln --bg --delay-ms 2000 wifi-connect /sys/autostart/10-wifi.lnk -- MySSID
ln /mnt/sd/apps/fileman.lexx /mnt/sd/fileman.lnk -- /mnt/sd/docs
```

Ярлык — обычный текстовый файл формата LEXX-LINK-1, а **не** POSIX-симлинк. Операции чтения и копирования ярлыка работают с самим файлом; команда оболочки `*.lnk` запускает его цель.

Цели могут быть именами встроенных программ (например, `board`) либо путями к `.lexx`. Цепочки ярлыков не поддерживаются.
