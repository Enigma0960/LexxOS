# `gb-ppu-test`

render Game Boy PPU background test.

## Справка shell

```text
gb-ppu-test - render Game Boy PPU background test

Seeds Game Boy VRAM with a deterministic tile background, renders it through the PPU background renderer and blits the result to the primary display.

Usage:
  gb-ppu-test
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
