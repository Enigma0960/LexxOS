# `display-fill`

fill display with one color.

## Справка shell

```text
display-fill - fill display with one color

Clears the selected display using a named color or raw RGB565 value.

Usage:
  display-fill <color> [name]

Arguments:
  color required - fill color: rgb565 value or color name
  name - display device name
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
