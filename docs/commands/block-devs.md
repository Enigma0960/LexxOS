# `block-devs`

show registered block devices.

## Справка shell

```text
block-devs - show registered block devices

Lists block devices registered in DeviceManager and shows their current readiness and geometry.

Usage:
  block-devs
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
