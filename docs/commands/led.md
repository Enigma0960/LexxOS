# `led`

Задаёт состояние индикаторного светодиода.

## Справка shell

```text
led - set status LED state

Usage:
  led <on|off|toggle>

Arguments:
  state required - status LED state
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
