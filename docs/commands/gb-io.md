# `gb-io`

test Game Boy IO registers.

## Справка shell

```text
gb-io - test Game Boy IO registers

Exercises the minimal Game Boy joypad, timer, divider, LY and interrupt flag model without loading a ROM.

Usage:
  gb-io
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
