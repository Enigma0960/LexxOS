# `fs-info`

show VFS diagnostic information.

## Справка shell

```text
fs-info - show VFS diagnostic information

Shows VFS mount slots, active mounts, mounted FAT volumes and tmpfs usage.

Usage:
  fs-info
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
