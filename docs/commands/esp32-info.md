# `esp32-info`

Показывает версию ESP-IDF, сведения о chip/flash, reset и heap.

## Использование

```text
esp32-info
```

## Наличие в сборке

Условие регистрации: ESP-IDF. Наличие команды не подтверждает подключение устройства
или поддержку всех операций конкретной конфигурацией. Подробности группировки:
[матрица команд](../command-matrix.md).

[Descriptor и реализация](../../src/lexxos/apps/core/esp32_info_program.cpp) — источник параметров;
`help esp32-info` показывает справку текущей сборки.
