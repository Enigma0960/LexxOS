# `input-test`

print pending input events.

## Справка shell

```text
input-test - print pending input events

Reads pending input events from the primary input device or from the selected input device.

Usage:
  input-test [name]

Arguments:
  name - device name
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
