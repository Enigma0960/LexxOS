# `rename`

rename a writable VFS file or directory.

## Справка shell

```text
rename - rename a writable VFS file or directory

Alias for mv. Renames or moves a file or directory inside the same writable filesystem.

Usage:
  rename <source> <target>

Arguments:
  source required - readable VFS source file
  target required - writable VFS target file
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
