# `help`

show program list.

## Справка shell

```text
help - show program list

Shows all registered LexxOS programs or detailed help for one selected program.

Usage:
  help [program]

Arguments:
  program - program name to describe
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
