# `sync`

synchronize mounted writable filesystems.

## Справка shell

```text
sync - synchronize mounted writable filesystems

Flushes mounted filesystems; in the simulator --sd-dir also reconciles the host directory with FAT32.

Usage:
  sync
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
