# `gamepad-test`

print current gamepad state.

## Справка shell

```text
gamepad-test - print current gamepad state

Reads one gamepad state sample. Without a name it uses the primary gamepad.

Usage:
  gamepad-test [name]

Arguments:
  name - device name
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
