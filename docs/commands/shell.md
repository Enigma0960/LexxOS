# `shell`

start interactive LexxOS shell.

## Справка shell

```text
shell - start interactive LexxOS shell

Starts the interactive LexxOS shell. When it is called from an already running shell, it prints the banner and returns.

Usage:
  shell
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
