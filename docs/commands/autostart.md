# `autostart`

`/sys/autostart` — доступный для записи псевдоним VFS для `/mnt/sd/.lexx/autostart`.
Для сохранения настроек SD должна быть смонтирована в RW. При загрузке shell
ждёт появления `/mnt/sd`, получает список до 24 файлов `.lnk` в алфавитном
порядке и запускает их последовательно. `delay_ms` каждого ярлыка отсчитывается
после предыдущего запуска; общая задержка выполняется перед первым.
Интерактивная программа получает фокус, следующий запуск ждёт его возврата
оболочке. Фоновые задачи используют соответствующий режим ProgramSupervisor.

```text
autostart status
autostart delay 2500
autostart disable
autostart enable
ls /sys/autostart
```

Настройки сохраняются в `/mnt/sd/.lexx/autostart.conf`:

```ini
enabled = 1
delay_ms = 2500
```

По умолчанию автозапуск включён с общей задержкой 1000 мс. Изменения
применяются при следующей загрузке. Файл можно редактировать напрямую.
`/tmp` не подходит для постоянных ярлыков. Без смонтированной SD каталог пуст.
