# `autostart`

Управляет автоматически запускаемыми ярлыками LexxOS.

## Синтаксис

```text
autostart
autostart status
autostart list
autostart delay <milliseconds>
autostart run
```

- `status` — расположение виртуальной папки, конфигурации и значение общей задержки.
- `list` — вывод ярлыков из виртуальной папки с режимом и задержкой.
- `delay N` — сохраняет глобальную задержку (0–600000 мс) в файл `/mnt/sd/.lexx/autostart.conf`.
- `run` — повторно активирует очередь автозапуска без перезагрузки.

## Хранение и порядок

Виртуальная папка `/sys/autostart` сохраняет файлы на SD по адресу `/mnt/sd/.lexx/autostart`. Она существует в дереве VFS даже когда карта ещё не смонтирована. Без доступной SD очередь не запускается.

После готовности SD и общей задержки ярлыки запускаются в лексикографическом порядке имени. Перед каждым ярлыком применяется собственная задержка `delay_ms`. Фоновые задачи запускаются и не блокируют очередь; для задач переднего плана автозапуск ждёт их завершения, сохраняя работу терминального ввода и переключения задач.

Чтобы задать порядок, используйте имена `10-network.lnk`, `20-clock.lnk` и т.д. На одну очередь поддерживается не более 16 ярлыков.

## Пример

```text
autostart delay 3000
ln --bg --delay-ms 500 wifi-connect /sys/autostart/10-wifi.lnk
ln --fg --delay-ms 1000 /mnt/sd/apps/fileman.lexx /sys/autostart/20-fileman.lnk
ls /sys/autostart
autostart list
autostart run
```

Изменённая через `autostart delay` общая задержка действует при следующем запуске очереди (или перезагрузке).
