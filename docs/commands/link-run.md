# `link-run`

Запускает сохранённый ярлык LexxOS с расширением `.lnk`.

## Синтаксис

```text
link-run <file.lnk> [additional args...]
```

К сохранённым аргументам добавляются переданные в момент запуска. Режим foreground/background выбирается внутри ярлыка. Фоновый запуск возможен только для программ с разрешением `allowBackground`; вывод фоновых программ по умолчанию скрыт, процесс можно увидеть через `jobs` и остановить командой `stop`.

## Примеры

```text
link-run /mnt/sd/fileman.lnk
/mnt/sd/fileman.lnk
/mnt/sd/fileman.lnk /mnt/sd/music
```

Задержка `delay_ms` применяется при автозапуске; обычный ручной запуск происходит немедленно. Оболочка автоматически перенаправляет вызов файла `.lnk` в `link-run`.
