# `display-info`

show display device information.

## Справка shell

```text
display-info - show display device information

Shows display size and native pixel format. Without a name it uses the primary display.

Usage:
  display-info [name]

Arguments:
  name - device name
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
