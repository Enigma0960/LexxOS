# `gb-irq`

test Game Boy CPU interrupt handling.

## Справка shell

```text
gb-irq - test Game Boy CPU interrupt handling

Exercises CPU interrupt dispatch, priority, IF/IE clearing and HALT wake-up without loading a ROM.

Usage:
  gb-irq
```

## Доступность

Доступна в стандартной или full-сборке в зависимости от feature-флагов платы. Документ соответствует LexxOS 0.0.7.
