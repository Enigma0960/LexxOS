# Отчёт разрешённых профилей памяти — 18 ноября 2026

Проверено на host после переноса выбора профиля в CMake. Значения получены
компиляцией `runtimeProfile()` с флагами и include paths соответствующих целей
из Ninja compilation database. SDK/Lyra строки — host-компиляция профиля,
а не измерение памяти работающей платы. Числовые контракты дополнительно
проверяются `memory_profiles_tests.cpp` и `sdk_memory_profiles_tests.cpp`.

Все размеры ниже — байты. Ноль в SDK/host kernel budget означает, что
LexxOS не резервирует собственную арену этого типа. Это не физический объём RAM.
Сборки `minimal`, `standard` и `full` сохраняют одинаковый профиль host.

| Цель | Heap | Stack pool | Task slots | Console mirror stack | UI controls / tree nodes | Image cache |
|---|---:|---:|---:|---:|---:|---:|
| `host-minimal` | 0 | 0 | 0 | 4096 | 32 / 32 | 196608 |
| `rp2040` | 129024 | 0 | 0 | 4096 | 12 / 16 | 24576 |
| `rp2350` | 229376 | 0 | 0 | 4096 | 12 / 16 | 24576 |
| `picocalc_pico2w` | 229376 | 0 | 0 | 8192 | 16 / 16 | 24576 |
| `rp2040_heap_96k` | 98304 | 0 | 0 | 4096 | 12 / 16 | 24576 |
| `picocalc_pico_w_heap_88k` | 90112 | 0 | 0 | 4096 | 12 / 16 | 24576 |
| `rp2040_no_freertos` | 0 | 0 | 0 | 4096 | 12 / 16 | 24576 |
| `esp32` | 0 | 0 | 0 | 4096 | 32 / 32 | 196608 |
| `esp32s3` | 0 | 0 | 0 | 8192 | 32 / 32 | 196608 |
| `esp32p4` | 0 | 0 | 0 | 8192 | 32 / 32 | 196608 |
| `Lyra` | 262144 | 98304 | 8 | 8192 | 64 / 64 | 196608 |
| `host-standard` | 0 | 0 | 0 | 4096 | 32 / 32 | 196608 |
| `host-full` | 0 | 0 | 0 | 4096 | 32 / 32 | 196608 |

`rp2040` и `rp2350` используют FreeRTOS; строка `rp2040_no_freertos` явно
проверяет сборку без него. `esp32s3` и `esp32p4` включают слой `espidf_lcd`.
Базовый ESP32 — без LCD-слоя. RP2040 с 96/88 КиБ проверяет явное переопределение
`LEXXOS_PICO_FREERTOS_HEAP_KB`. У SDK fixtures без `LEXXOS_BOARD_NAME` поле
`origin.board` остаётся `base`; firmware target получает настоящее имя платы.

Полный отчёт на работающей сборке доступен командой `mem profile`. Она выводит
скомпилированные лимиты, а текущую занятую память показывают `mem` и `tasks`.
Бюджеты и физическая карта памяти этим рефакторингом не изменены.

Описание генерации и выбора — [профили памяти](runtime-memory-profiles.md).
