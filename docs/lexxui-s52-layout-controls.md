# LexxUI S5.2 — системная раскладка, данные контролов и PRNG

Основано на существующем **LexxUI ABI v1** (`Control=48`, `Document=420`,
`Event=40`) и `graphics` syscall 25. Старые окна и номера операций 6/7/8
сохранены. Реализация располагается **в ОС** (`src/lexxos/ui/guest_ui.h`),
гостевой SDK содержит только объявления и `ecall`-обёртки.

## Новые контролы (kind)

- `5 ProgressBar`: значение `value` в диапазоне 0..100, не принимает фокус.
- `6 Slider`: значение 0..100, `Left/Right` изменяют на 5, событие `Change`.
- `7 ListView`: один список на окно, до восьми строк UTF-8 по 31 байту,
  `Up/Down` изменяют выбранную строку, `Enter` возвращает `Activate`;
  `Event.value` — индекс, `Event.text` — название строки.

`Tab` переключает фокус между контролами, `Esc` закрывает окно.
Для совместимости `Up/Down` сохраняют переход между контролами, кроме
сфокусированного `ListView`, где они меняют строку. `TextField` пока
редактируется печатными ASCII; UTF-8 отображается встроенным шрифтом.

### Автоматическая компоновка

`Control.flags |= 2` (или `lexx::ui::flag_auto_layout`) поручает ядру
назначить x=10, ширину=экран-20, y последовательно после заголовка.
`height=0` выбирает типовую высоту элемента, `height>0` сохраняет указанный
размер. Прочие контролы сохраняют старые абсолютные координаты.
Если элементы не помещаются в экран, `show` возвращает ошибку; автоматическая
прокрутка, колонки и модальные окна относятся к следующему этапу.

### Смена значений без пересоздания окна

- `ui::update_control(Control const&)` — операция 9, меняет `text`, `value`
  и флаг `disabled` существующего контрола с тем же ID и kind. Размер и
  положение остаются неизменными; текущий фокус не сбрасывается.
- `ui::set_items(ListItems const&)` — операция 10. `ListItems` занимает ровно
  260 байт: `id:u16`, `count:u16`, восемь строк по 32 байта. Одна ListView
  на окно. Старый `Document` не растёт.

Система проверяет адреса гостевой памяти, нуль-терминацию строк, ID и типы.
Ввод и отрисовка допускаются только при владении графическим режимом и
наличии фокуса; команды копируются в память ОС. Изменения вызывают
перерисовку; если дисплей временно занят, она повторяется на следующем
`poll()` без потери значения в системной модели.

Изображения, шрифты, тема и графический буфер по-прежнему находятся в ОС.
Текущий рендерер использует полную перерисовку; минимизацию ROI для
виджетов целесообразно сделать после стабильных тестов на Lyra.

## Генератор случайных чисел SDK: random.h

Добавлен переносимый `lexx::random::Generator` на xoshiro128++ (128-битное
состояние, детерминированный `seed(u32)`, `next_u32()`, `below(n)`,
`range(a,b)`). `below(n)` использует rejection sampling без modulo bias;
`range` включает обе границы. Не требуется новый syscall; функции доступны
на RV32I, включая конфигурации без аппаратного умножения.

**Это не криптографический RNG.** Для ключей, токенов, паролей, TLS и
любого security-critical применения требуется отдельный источник настоящей
энтропии, драйвер платформы и системный интерфейс.

## Сборка/проверка

```sh
cmake --build build/host-full --target lexxos_sim app-ui-demo -j 12
cmake --build build/host-full --target lexxos_random_tests
```

Обновить `ui-demo.lexx` в каталоге SD, перезапустить эмулятор и запустить
`/mnt/sd/lexx/ui-demo.lexx`. Проверить список, стрелки, Tab, Slider,
синхронизацию ProgressBar и сохранение фокуса при `update_control()`.
На Lyra повторить тест со стандартными драйверами клавиатуры и дисплея.

## Что остаётся на S5.3

Динамические растровые шрифты из `:/fonts/...` и VFS (включая верификацию
лицензии), измерение текста, обрезка, перенос, сложные layout-контейнеры,
модальные диалоги, scrolling списков длиннее восьми элементов,
унифицированные указатели мыши и touch. Текущая реализация S5.2 не
претендует на полноценную оконную систему с несколькими процессами.
