# LexxOS external programs: troubleshooting

## `lexx-run: failed: instruction-limit executed=500000`

Это означает, что `.lexx` программа была запущена с конечным лимитом инструкций и не завершилась до достижения этого лимита.

Для интерактивных программ, которые ждут клавиатуру, конечный общий лимит инструкций неудобен: программа может корректно работать, вызывать `lexx::yield()` и просто ожидать ввод.

Текущая политика:

- `--max-steps 0` означает запуск без лимита инструкций.
- Значение по умолчанию тоже `0`, то есть интерактивные программы по умолчанию не завершаются по instruction limit.
- Для диагностики runaway-кода можно явно указать конечный лимит, например `--max-steps 500000`.

Примеры:

```text
lexx:/> lexx-run /mnt/sd/ext/hello.lexx
lexx:/> lexx-run --max-steps 0 /mnt/sd/ext/hello.lexx
lexx:/> lexx-run --max-steps 500000 /mnt/sd/ext/hello.lexx
```

Остановка интерактивной программы должна выполняться одним из штатных способов:

```text
q
Ctrl+C
stop <id>
```

## Демо слишком часто печатает `waiting for keyboard input`

Демо `examples/lexx/hello` теперь печатает строку ожидания только один раз при старте. Дальше оно молча ждёт события клавиатуры, чтобы не засорять консоль и не тратить инструкции на повторный вывод.
