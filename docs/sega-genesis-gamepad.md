# Контроллер Sega Genesis

LexxOS поддерживает трёхкнопочный контроллер Sega Genesis через расширитель портов `PCF8575`.

Драйвер находится в:

```text
src/lexxos/devices/input/sega_genesis_gamepad.h
src/lexxos/devices/input/sega_genesis_gamepad.cpp
```

## Подключение `dev_pico`

Сигналы направлений и кнопок подключены к `kbd-pcf8575`, а линия выбора фазы `TH` управляется напрямую через Pico:

```text
UP:       PCF8575 P4
DOWN:     PCF8575 P5
LEFT:     PCF8575 P6
RIGHT:    PCF8575 P7
B/A:      PCF8575 P14
C/START:  PCF8575 P15
TH:       GP2
```

Конкретная распиновка задаётся структурой `SegaGenesisGamepadPins` в board descriptor.

## Опрос

Драйвер последовательно читает две фазы:

1. `TH = 1`: направления, кнопки `B` и `C`.
2. `TH = 0`: сигнатура трёхкнопочного контроллера, кнопки `A` и `START`.

После опроса `TH` возвращается в высокий уровень.

Перед каждым чтением используемые линии `PCF8575` отпускаются записью единиц. Для каждой фазы выполняется до трёх
попыток. Состояние, в котором все шесть входных линий одновременно равны нулю, считается ошибкой обмена и не публикуется
как нажатие всех кнопок.

## Представление кнопок

Состояние переводится в общий `GamepadState`:

```text
Sega C     -> GamepadState::a
Sega B     -> GamepadState::b
Sega START -> GamepadState::start
Sega A     -> GamepadState::select
```

Такое отображение сохраняет текущий общий интерфейс gamepad без добавления Sega-специфичных полей.
