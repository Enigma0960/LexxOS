## Проверка независимого публичного снимка

При подготовке публичного репозитория исходники перенесены без истории Dev;
FreeRTOS закреплён на том же commit. Удалён локальный путь из поля автора примера
cat, согласованы нейтральные имена в тесте completion (имя остаётся длиннее 32 байт).

Первичная проверка выявила потерю команд из pipe и timeout `lexxos_host_stdin`.
Причина: foreground-команда запускается в отдельной задаче, а shell продолжает
обрабатывать пакет stdin и направляет следующую строку ещё работающей программе.

Исправление от 2026-10-25: host с неинтерактивным stdin ожидает завершения foreground
задачи перед продолжением shell. TTY сохраняет интерактивную маршрутизацию ввода;
MCU и simulator этим host-условием не затрагиваются. Background-запуск остаётся
асинхронным. Пакетный сценарий не предназначен для управления интерактивными играми.

После исправления minimal/full host собраны с `LEXXOS_APPS=OFF`, `BUILD_TESTING=ON`
и static checks: **30/30 CTest в каждом профиле**. Регрессия stdin проверяет
20 последовательностей echo/rename/cat/rm с точным порядком результатов через pipe
и обычный файл, включая переходы между пакетами ввода. Отдельная PTY-проверка:
запуск top, Ctrl+C, возврат в shell, echo и exit — PASS.
Markdown проверен после завершения подключения FreeRTOS. Эти результаты закрывают
обнаруженный сбой host stdin; аппаратные и длительные тесты не выполнялись.
