# RTC DS3231 и EEPROM AT24C32

Модуль платы предоставляет два I2C-устройства:

- RTC DS3231 по адресу `0x68`;
- EEPROM AT24C32 по адресу `0x57`.

## Команды RTC

DS3231 является одним из backend-ов универсальных RTC-команд. Для явной проверки внешнего модуля используйте
`--source ds3231`; backend доступен только когда включён `LEXXOS_FEATURE_DS3231_RTC`.

По умолчанию для DS3231 используются зарегистрированная I2C-шина LexxOS с именем `debug` и адрес `0x68`:

```text
rtc-get --source ds3231
rtc-status --source ds3231
rtc-set --source ds3231 2026-06-11 14:30:00
rtc-set --source ds3231 2026-06-11T14:30:00
```

Шину и адрес можно указать явно:

```text
rtc-get --source ds3231 --bus debug --address 0x68
rtc-set --source ds3231 --bus debug --address 0x68 2026-06-11 14:30:00
```

`rtc-get` выводит дату, время и номер дня недели. Используется соглашение, близкое к ISO: понедельник имеет номер `1`,
воскресенье - `7`.

`rtc-status` читает регистр состояния DS3231 и показывает флаг остановки генератора. Установленный флаг означает, что
после потери питания или разряда батареи время может быть недостоверным. После успешной записи `rtc-set` очищает флаг.

## Использование AT24C32

AT24C32 подходит для небольших редко изменяемых данных:

1. параметров загрузки и последнего рабочего профиля;
2. имени платы, серийного номера и версии калибровки;
3. яркости дисплея, раскладки клавиатуры и профиля скорости SD;
4. последнего panic-кода, причины перезагрузки и счётчика запусков;
5. часового пояса и источника последней синхронизации RTC;
6. safe-mode и данных восстановления.

Не используйте EEPROM для частого append-only логирования: ресурс циклов записи ограничен. Будущий драйвер должен
учитывать границы страниц, проверять записанные данные и уменьшать износ часто обновляемых ячеек.

Для корректного случайного чтения AT24C32 в `I2cBus` потребуется общая операция `writeRead`: фиктивная запись адреса с
последующим чтением через repeated start.
